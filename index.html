1. NSO / Categoría de etiquetas

Lee semánticamente código, categoría, NSO y formato histórico aunque estén movidos de columna. También recupera CONTIENE / ingredientes desde hojas de etiqueta Ancha cuando existan.

Sin archivo cargado.

2. Descripción NR

Fuente principal de la descripción regulatoria visible. El importador separa automáticamente texto y NSO aunque estén cruzados de columna, y usa el texto completo para decidir Normal, Larga, NSO Triple o Ancha.

Sin archivo cargado.

3. Códigos / Armados

Relaciona número de armado, código asignado y descripción. El NSO es opcional: cuando aplique, puedes buscarlo por código directamente en la base NSO / Categoría.

Sin archivo cargado.

4. Descripción productos

Conectada a Etiqueta General. Reconoce “Código Producto” y “Descripción”. Esta base grande se guarda en IndexedDB para no saturar el navegador. Si trae “Unidades por caja”, también las completa.

Sin archivo cargado.

Estado y sincronización

Cargando Firebase...
Firebase es la fuente central. Al abrir la plataforma, la base se descarga automáticamente. LocalStorage e IndexedDB quedan como caché y respaldo temporal si no hay conexión.

Qué se sincroniza

✓ NSO / Categorías · ✓ Descripción NR · ✓ Armados · ✓ Descripción productos · ✓ Ingresos manuales · ✓ Plantillas y configuración compartida.
No se sincronizan las impresoras seleccionadas: cada computador mantiene su propia ZT410 / ZT231.
